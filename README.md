# Rusho — Personal Portfolio

I'm **Rusho**. I like AI, I run a **homelab**, and I host servers for friends. Working toward a career as a **security architect**.

Daily stuff: **Docker**, **LLMs**, **Linux**.

## The Site

A book-style page — cream paper, serif type, chapters. Built with plain HTML and CSS. Zero JavaScript, zero frameworks, zero external dependencies.

- **Hero** — name, tagline, quick blurb
- **About** — the story above
- **Skills** — AI/LLMs, Docker & Linux, homelab & self-hosting
- **Projects** — placeholder cards waiting for your real work
- **Contact** — email CTA + social links

## Getting Started

Open `index.html` in any browser — that's it.

## Customizing

1. **Text** — edit the sections in `index.html`
2. **Email / socials** — update the `#contact` links and `mailto:` address
3. **Colors** — tweak the variables at the top of `css/style.css`
